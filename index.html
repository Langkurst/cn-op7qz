NZ Redact Open source, November 2026

In Xero's May 2026 survey, 40% of New Zealand small businesses said data privacy and security was a reason they weren't using AI, or weren't using it more. NZ Redact takes the personal details out of text before it goes into an AI tool and puts them back into the answer afterwards. It knows New Zealand IRD, bank and NHI numbers and checks them against Inland Revenue's and Health New Zealand's own rules, and the page isn't allowed to connect to anything, so the text stays on your computer.

In a blind test on documents it hadn't seen before, it found 95% of the numbers, dates, emails, phone numbers and addresses and about two thirds of the names, up from a quarter in the first version, so names still need a person to read through them. An AI coding agent wrote the code and the rules, and separate agents wrote the test documents without seeing the rules.

Ruru Open source, November 2026

Ruru is a free app for Bose headphones that runs on Windows, macOS, Linux, Android and iPhone from the same code. It changes the listening modes, noise cancelling, Wind Block, Immersive Audio, the equaliser and multipoint, and on Windows it sits in the tray with the battery level and a mode switch. There's no account, no cloud and no analytics, and the Android version doesn't even ask for internet access.

It started from Earshot, an open-source Android app that had only been tested on the newer QC Ultra Headphones and had known problems with the first generation, which is the pair I own. Testing on my own headphones from my PC found the likely cause, the AI agents fixed it, and changes to the equaliser, the mode switch and a saved custom mode were each checked on the real headphones and put back afterwards.

So far it's only been tested on Windows. The Android, Mac and Linux versions build but haven't been tried with headphones yet, and the iPhone version can only run its demo, because iOS doesn't let apps open the Bluetooth channel Ruru uses everywhere else. There's no release yet.

Working with AI

I use Claude and ChatGPT every day. Claude is connected to my Gmail, Google Calendar, Google Drive and 11 other services, and I've set up 10 saved skills for jobs I do over and over, like release checklists and checking wording.

My main rule for the agents is that they don't buy anything, publish anything, send anything or permanently delete anything without asking me first. These are three times I had to step in.

  1. 14 October 2026 On KeaClip the AI suggested adding cloud storage and said a charge "isn't impossible in theory". I told it I must never be charged, and it put hard limits in place, with tests, before the first upload.
  2. 15 October 2026 On SwimSorted the AI twice recommended buying a domain before anyone had checked the name could be used. I asked for that check, the name turned out to be a registered trade mark in Australia, and I renamed the product.
  3. 7 November 2026 On SwimSorted the AI kept writing slogans for the website, so I asked for wording that reads like I wrote it myself and for a build check that fails if the slogans come back.

No person has reviewed the code in my projects yet. Every review in the project records is one AI checking another AI's work.
